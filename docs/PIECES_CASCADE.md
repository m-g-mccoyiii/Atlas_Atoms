# Overreact: what the sixty pieces do in the cascade game

Drafted 2026-11-10. Not built. Every piece has one job, and every job is a way to make the cascade bigger. The owner set the frame: the reactions dealt each page are random from a pool, and unlocks and pieces change that deal, the setup, what can join, how long it runs and what it pays.

## The deal: what you are dealt each page

| Piece | What it does |
|---|---|
| index cards | dealt 6, not 5 |
| carousel | one free redraw a page |
| raven | carries one reaction to the next page |
| crystal ball | shows the next deal |
| monkey's paw | swap one dealt reaction for any you own. 3 a run |
| unlabeled bottle | one extra reaction from outside your pool |
| ouija board | it picks one. play it and it counts twice |
| loupe | rare reactions come up twice as often |
| dropper | every reaction has one more charge |
| log book | one reaction from last page is dealt again |
