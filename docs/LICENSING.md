# Licensing assessment

Working notes for selling the Steam edition. This is research, not legal advice. Have a lawyer review it before release. Anything marked **UNVERIFIED** was not confirmed at the primary source and must be checked.

## Rule for this project

Everything that ships must be usable in a commercial product. Check the licence at the source, not a summary. Prefer MIT, BSD, Apache 2.0, CC0, SIL OFL. Avoid GPL and AGPL code in the shipped game, and avoid Creative Commons NonCommercial and ShareAlike material.

## What ships today

| Item | Licence | Verdict |
| --- | --- | --- |
| Three.js r128 | MIT | Allowed. Keep the licence text (`packages/core/vendor/LICENSE-three.txt`). |
| IBM Plex Mono, IBM Plex Serif | SIL OFL 1.1 | Allowed. Can be bundled and used in a commercial game. Fonts cannot be sold alone. Keep `OFL.txt`. |
| Spectra | Generated by `packages/core/js/spectra.js` from textbook rules | No third-party data. Labelled in-game as simulated. |
| Sounds | Synthesised in code | No sample licences needed. |
| Compound list, formulas, facts | Written for the project, checked with `tools/verify_compounds.py` | Facts are not copyrightable. Descriptions are original text. |

## Needed for the Steam build

| Item | Notes | Status |

## Data sources considered for later

| Source | Concern |
| --- | --- |
| PubChem | US government data is generally free to use, but records submitted by others can carry their own terms. NCBI asks for a disclaimer and credit. Check each record's source before bundling. |
| NIST Chemistry WebBook | Check its copyright notice before bundling spectra. **UNVERIFIED** |
| Open Reaction Database | Share-alike licence (CC BY-SA). Bundling would require the derived data to be shared the same way. Avoid bundling. |
| Open Babel | GPL. Do not link or ship it in the game. |
| xtb | LGPL. Usable only as a separately shipped, replaceable library, with source offer. Needs review. |
| Noto Emoji or other emoji sets | Check the licence of the specific set. **UNVERIFIED** |
| Unreal Engine | If the project ever moves engines, the royalty terms must be read at the source. **UNVERIFIED** |

## Audience and policy notes

- The kids' web edition is for a child. Do not add accounts, analytics or ads. If it is ever offered to children generally, US COPPA and similar rules apply.
- The Steam edition targets a general audience. Check Steam's content survey and age rating requirements when the store page is made.

## Names and trademarks

"Meitner Analytical" is a working title. Search trademark databases and Steam for conflicts before a store page goes up. "Atlas' Atoms" is the family project name and the kids' app name.
